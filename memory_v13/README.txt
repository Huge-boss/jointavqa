统一流程

与native一致则结束。分歧时，只有有效描述、未截短且非NONE/GLOBAL的索引才能触发一次不超过12秒回看；定位未知不再用音频空档/片段中点代替。短片或没有可用索引时直接全局核验。局部工具只见原问题、真实片段与实际源音频覆盖，不见旧观察或候选。最后独立上下文再次看原始全局和新局部观察；只有其自由生成答案同意候选才修改native，否则保留native。
