来源约束的音画证据记忆与分歧复核 V8（完整方案实验）

研究假设：弱音画模型的问题不只是记忆长度，而是观察覆盖不足、声音和人物错误绑定、局部信息覆盖全局及无证据的答案改写。将实际观察范围与模型生成笔记分开，并对答案改变进行独立全局复核，可能减少回看造成的改错。
本轮是整套方法验证，不做消融。是否可成为论文贡献必须经过相关工作比对、保留集测试和后续消融；不预先宣称创新或提升。

流程：复用原始native答案→无候选答案提示的全局VISUAL/AUDIO/LINK/NEED/FOCUS观察→缺失证据驱动至多一次12秒局部观察→原始全局音画+带来源的笔记重新作答→若与native答案不同，第三次全局查看区分两种假设；新答案必须与复核一致。
生成的时间定位只用于检索，不作为真实标注。笔记来源时间由裁剪器记录；人物仅使用局部描述，无视觉嘴型等证据不得把脸声硬绑定。短于12秒不重复裁剪整段。模型生成的笔记仍可能幻觉，不能把“来源可追踪”等同“内容已验证”。

只复用同题同模型的native输出与历史耗时，运行文件中不含标签/正确性。评分独立读取标签。baseline不重新跑全量，仅pilot核对缓存输出与当前原生路径一致。最坏新增4次调用（逻辑总数5次），明确承认额外成本；本轮不承诺比baseline快。
仅使用既定Joint571/AV642开发题。相同greedy/seed/选项和主评分，保留全部失败、未解析和版本。不会按题目挑最佳方法。新0/1/3三张卡分题，2卡不碰；每卡一个完整模型。权重/环境不改，旧代码和结果不覆盖。

参考来源（不是完整复现）：
VideoARM，https://arxiv.org/html/2512.12360v2 ，借鉴全局/局部感知与工具结果分离。
WorldMM，https://arxiv.org/html/2512.02425v2 ，借鉴多模态证据检索与原始感知核验。
VideoAgent（记忆版），https://arxiv.org/abs/2403.11481 ，借鉴时间事件与实体线索；此处不引入它的外部模型。
本方案拟研究的区别：对短音画片段使用覆盖/未知信息驱动的惰性记忆，并用全局对照复核限制未经确认的答案修订。组成模块并非都新，整合是否具有创新和实际价值尚待验证。

启动顺序：本地测试→上传独立文件→prepare.py冻结代码/输入/依赖/无标签缓存→run_campaign.py。每模型每数据集先6题技术pilot，再三卡完成20%；错误停止诊断，不因正确率低中途删题或追分。
完成输出runs/reports内总表JSON、逐题配对、各类别分项、中文报告；runs/complete_results.tar.gz保留证据。
进一步实验由跟进任务在整轮完成后统一比较，只有明确设计理由才写独立新版；不自动动用剩余80%。

V7预检6题全部原生输入/文本/重复性一致，但自由生成观察格式0/6可用，因此正式dev20未运行。V8仅修复工具观察接口：强制字段边界和时间槽选项，视觉/音频/链接/缺失正文自由greedy生成，上限24/24/16/16 token并记录截短标志；观察不包含选项答案。正式答案仍自由生成，基线和评分不变。生成格式通过不等于观察事实正确。V7源码、日志、成本全部保留。
